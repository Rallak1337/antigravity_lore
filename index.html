About Antigravity

Antigravity is an internal automation tool designed for personal channel management, automated video uploads, and thumbnail management via the YouTube Data API v3.

This tool is used exclusively by the channel owner to streamline creative workflows and content scheduling.

Privacy Policy

Last Updated: September 2026

Antigravity values your privacy. This Privacy Policy describes how information is handled when using this application.

1. Data Collection & Access

Antigravity requests access to the YouTube Data API solely to perform authorized actions on connected YouTube channels, including uploading videos, updating video metadata, and uploading thumbnails as instructed by the user.

2. Use of Google User Data

The application only accesses channel data with explicit authorization via OAuth 2.0. We do not sell, transfer, or distribute your personal information or Google user data to any third party.

3. Data Storage & Security

Authentication tokens are stored locally on the user's private workstation in encrypted/secured files. No authentication data or channel information is stored on external servers or transferred over unauthorized channels.
